## 1. חמישה ערוצים
המצב התודעתי משאיר חתימה בחמישה ערוצים בו-זמנית. ערוץ אחד יכול לשקר (בעיקר המחשבה: "אני רגוע לגמרי"); שלושה ערוצים תואמים — זו אבחנה אמינה. **הגוף הוא הערוץ הישר ביותר; השפה היא הקלה ביותר לתפיסה.**

## 2. ערוץ הגוף
| | 3D | 4D | 5D |
|---|---|---|---|
| נשימה | קצרה, גבוהה בחזה, נעצרת | לא סדירה; אנחות | איטית, בטנית, נשיפה ארוכה |
| שרירים | לסת, כתפיים, בטן מכווצות | מתחלף; גלי שחרור ומתח | רכות עם יציבות |
| מבט | צר, ממוקד-איום, מסך | פנימה, מזוגג | רחב, היקפי, רך |
| אנרגיה | דריכות או קריסה | תנודתית | ערנות שקטה |
| בטן/חזה | קשר בבטן, לחץ בחזה | רגישות יתר | חום/מרחב בחזה |
| תנועה | ממהר, קופצני | מהוסס | מדויק, לא ממהר |

פיזיולוגית 🔬: 3D ≈ הפעלה סימפתטית/קיפאון דורסלי; 5D ≈ מצב וגאלי-ונטרלי (ביטחון וחיבור), HRV גבוה. זו הסיבה שהמעבר מתחיל תמיד בגוף.

## 3. ערוץ המחשבה
- **3D:** מהירה, לולאתית, שחור-לבן. תוכן: איומים, השוואות, אשמים, "מה יהיה", "מה יגידו". המחשבה נחווית כ**עובדה**. אין מרווח בין מחשבה לתגובה.
- **4D:** מחשבה על מחשבה. ניתוח עצמי, חיפוש משמעות, "למה אני ככה". המחשבה נחווית כ**סיפור שאני מספר** — אבל עדיין מרתק מאוד. סכנה: אינטלקטואליזציה אינסופית.
- **5D:** מעטה, איטית, פונקציונלית. רווחים של שקט בין מחשבות. המחשבה נחווית כ**אירוע שמופיע במודעות** — כמו צליל. רעיונות מגיעים "שלמים" (תובנה) ולא נטחנים.

**מבחן מהיר:** "האם אני יכול לא להאמין למחשבה הזו כרגע?" לא ← 3D. כן, במאמץ ← 4D. היא כבר חלפה ← 5D.

## 4. ערוץ הרגש
| | 3D | 4D | 5D |
|---|---|---|---|
| טון יסוד | פחד, כעס, בושה, קנאה, שעמום | געגוע, אבל, בלבול, התלהבות, רגישות | שלווה, תודה, חמלה, שמחה שקטה, יראה |
| יחס לרגש | "הרגש הוא אני" / הדחקה | "יש לי רגש ואני חוקר אותו" | "רגש עובר דרכי" |
| משך | שעות–ימים; נדבק | גלים | דקות; משאיר ניקיון |
| כלפי אחרים | שיפוט, הגנה | הזדהות יתר, ספיגה | חמלה עם גבול |

שים לב: ב-5D **יש** עצב וכעס. ההבדל הוא שאין התנגדות להם ואין סיפור סביבם. כעס 5D הוא "לא" ברור ונקי, בלי רעל.

## 5. ערוץ השפה — הכי קל לתפוס
הקשב למילים שיוצאות ממך (ולשיח הפנימי):

| 3D | 4D | 5D |
|---|---|---|
| "אני חייב / צריך / אין ברירה" | "אני בוחר / מנסה להבין" | "אני רוצה / זה נכון לי / בוא נראה" |
| "תמיד / אף פעם / כולם" | "אני שם לב שאני..." | "כרגע..." |
| "הוא עשה לי / בגללם" | "מה זה מפעיל בי?" | "מה נדרש כאן?" |
| "אין לי זמן / אין מספיק" | "אני לומד לסמוך" | "יש מספיק" |
| "אבל" | "וגם, אבל..." | "וגם" |
| צודק/טועה | אמת שלי/אמת שלך | שתי הזוויות חלקיות |
| תלונה, רכילות | עיבוד, שיתוף ארוך | תמציתי, שקט, הומור רך |

**תרגיל:** יום אחד ספור כמה פעמים אמרת "חייב/צריך". זה מדד 3D פשוט ואמין.

## 6. ערוץ הזמן והקשב
- **3D:** הזמן דוחק או נגרר. הקשב צר ונחטף (התראות, מולטיטסקינג). אתה בעתיד/בעבר >80% מהזמן. אוכל בלי לטעום.
- **4D:** רגעי נוכחות שמתחלפים בשקיעה פנימה. הקשב מופנה לעצמי. סינכרוניות מורגשות.
- **5D:** הזמן "מתרחב" — מספיקים יותר בפחות מאמץ; או נעלם (flow). קשב רחב ויציב: מודע לאדם שמולך, לחדר ולגוף בו-זמנית. פעולה אחת בכל רגע.

## 7. בדיקת מימד ב-60 שניות (לבצע 5× ביום)
עצור. בלי לשנות דבר, סרוק:
1. **נשימה** — איפה היא? (חזה/בטן; עצורה/זורמת)
2. **כיווץ** — לסת, כתפיים, בטן: 0–10?
3. **מחשבה אחרונה** — על מה? האם האמנתי לה?
4. **טון רגשי** — מילה אחת.
5. **זמן** — איפה הייתי: עבר / עתיד / כאן?

סיכום: **א / ב / ג** + תחום חיים. רשום (פתק בטלפון). אחרי שבוע יש לך **מפת חום אישית**: מתי, איפה ועם מי אתה בכל מצב. זה הנתון החשוב ביותר בכל התהליך.

עוגנים מומלצים: התעוררות · לפני ישיבה ראשונה · אחרי ארוחת צהריים · כניסה הביתה · לפני שינה.

## 8. מפת תחומי החיים
אף אחד אינו "במימד אחד". מלא (א/ב/ג) לפי שבוע של בדיקות:

| תחום | מצב דומיננטי | טריגר עיקרי ל-3D | מה מחזיר אותי |
|---|---|---|---|
| עבודה ומקצוע | | | |
| כסף וביטחון | | | |
| זוגיות | | | |
| הורות / משפחת מוצא | | | |
| גוף ובריאות | | | |
| זמן ולוחות זמנים | | | |
| יצירה ותחביבים | | | |
| לבד עם עצמי | | | |

דפוסים שכיחים: **"מקצוען-על"** — ג' בעבודה ויצירה, א' בזמן ובזוגיות · **"המחפש"** — ב' בכל מקום, א' בכסף · **"הנזיר בבית"** — ג' לבד, א' מול משפחת המוצא (המבחן הקלאסי: "אם אתה חושב שהתעוררת, סע לשבוע להורים").

## 9. מצבים מטעים — זיוף 5D
| נראה כמו 5D | בפועל | איך מבחינים |
|---|---|---|
| שלווה | ניתוק/הקהיה (קיפאון 3D) | אין חיוּת, אין חום בחזה; לא אכפת ≠ שלֵו |
| "הכול מושלם" | הכחשה, עקיפה רוחנית | נמנע משיחות קשות ומפעולה נדרשת |
| אהבה לכולם | ריצוי, חוסר גבולות | לא מסוגל לומר "לא" |
| התעלות, אופוריה | שיא 4D / היפומאניה | פחות שינה, דיבור מהיר, תחושת שליחות דחופה — **לקרקע, ואם נמשך — איש מקצוע** |
| "אני מעבר לאגו" | אגו רוחני | נפגע כשמפקפקים בזה |
| אי-היקשרות | הימנעות מאינטימיות | בדידות מתחת לפני השטח |

**מבחן הזהב:** 5D אמיתי **מגדיל** תפקוד, חום וקשר עם אנשים רגילים. אם הוא מקטין אותם — זה משהו אחר.

## 10. אימון הזיהוי — 3 רמות
1. **בדיעבד (שבועות 0–3):** "אתמול בישיבה הייתי ב-3D." יומן ערב.
2. **תוך כדי (שבועות 4–8):** "אני ב-3D עכשיו." עצם הזיהוי כבר מזיז אותך ל-4D — כי מי שמזהה הוא המתבונן.
3. **לפני (שבועות 9+):** מזהה את הכיווץ הראשון בגוף *לפני* התגובה, ובוחר. זו חירות.
