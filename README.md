# מצפן המימדים

אפליקציית PWA בעברית (RTL) לאימון תודעת 3D / 4D / 5D: בדיקת מימד של 60 שניות, ארגז כלים למעבר, נגן תרגולים, מסע של 12 שבועות, יומן ותובנות.
"מימד" כאן הוא **מצב תודעה** — לא טענה על מבנה היקום.

הכול מקומי: הנתונים נשמרים רק במכשיר (IndexedDB), בלי שרת, בלי חשבון, בלי אנליטיקס ובלי קריאות רשת. אחרי טעינה ראשונה האפליקציה עובדת גם במצב טיסה.

המפרט המלא: [SPEC.md](SPEC.md) · כללי העבודה: [CLAUDE.md](CLAUDE.md) · סקירת התוכן: [CONTENT-REVIEW.md](CONTENT-REVIEW.md)

## התחלה מהירה

```bash
npm install
npm run dev
```

נדרש Node ‎22.12 ומעלה.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח (בלי service worker) |
| `npm run dev:phone` | שרת פיתוח ב-HTTPS ברשת המקומית — לבדיקה על טלפון אמיתי |
| `npm run build` | בדיקת תוכן + טיפוסים + build ל-`dist/` (כולל service worker ו-manifest) |
| `npm run preview` | הגשת ה-build המקומי |
| `npm test` | בדיקות יחידה (Vitest) |
| `npm run e2e` | בדיקות קצה-לקצה (Playwright: iPhone 14, Pixel 7, דסקטופ) מול ה-build; צילומי מסך ב-`test-results/screens/` |
| `npm run e2e:qa` | סריקת QA של כל המסכים (320px, טקסט ענק, ערכה בהירה, מסך לרוחב, axe) + מדידת טעינה ב-worker יחיד |
| `npm run dist:check` | אחרי build: תקציב הטעינה הראשונית (250KB gzip), סריקת מפתחות, נכסי PWA |
| `npm run content:check` | ולידציה של `src/content/*.json` |
| `npm run content:review` | מפיק מחדש את `CONTENT-REVIEW.md` |
| `npm run icons` | מפיק מחדש את האייקונים ומסכי הפתיחה מתוך `tools/pwa-assets.mjs` |

## מבנה

```
src/content   תוכן (JSON) + סכמות Zod — מקור האמת הוא content-source/
src/domain    לוגיקה טהורה, בלי React ובלי Dexie — מכוסה בבדיקות
src/data      Dexie, repositories, גיבוי, שמירה אוטומטית
src/audio     AudioEngine — כל צליל עובר דרכו; הצלילים מסונתזים, אין קובצי אודיו
src/design    tokens, רכיבי בסיס, תרשימים
src/features  המסכים
src/app       ניווט, Shell, עדכון גרסה
src/lib       עזרים: bidi, ics, הורדה/שיתוף, PWA
```

## פריסה ל-GitHub Pages

1. ליצור מאגר ב-GitHub ולחבר אותו: `git remote add origin <url>` ואז `git push -u origin main`.
2. במאגר: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. כל דחיפה ל-`main` מריצה את `.github/workflows/deploy.yml`: בדיקות יחידה → build → `dist:check` → פריסה. בדיקות ה-e2e רצות במקביל ומדווחות, בלי לחסום פריסה.

ה-build משתמש בנתיבים יחסיים (`base: './'`) ובניתוב hash, ולכן עובד מכל תת-תיקייה בלי הגדרה נוספת.

שימו לב: ב-GitHub Pages בחשבון חינמי המאגר חייב להיות ציבורי — כלומר גם `content-source/`, `SPEC.md` ושאר הקבצים גלויים לכול.

## עדכון גרסה אצל המשתמשים

ה-service worker מוריד גרסה חדשה ברקע. האפליקציה אינה מתרעננת מעצמה: מופיעה הצעה שקטה "גרסה חדשה מוכנה — לרענן", ורק מחוץ לנגן התרגולים.

## בדיקות קבלה על iPhone פיזי

חלק מההתנהגות אי אפשר לבדוק באמולציה. להריץ `npm run dev:phone`, לפתוח את הכתובת מהטלפון (באותה רשת Wi-Fi) ולאשר את התעודה העצמית; או לבדוק ישירות באתר הפרוס.

- **אודיו** (`#/design` ← "אודיו — בדיקת קבלה"): הפעמון נשמע גם כשמתג השקט פועל; המסך אינו נכבה בזמן תרגול; נעילת המסך משהה, והחזרה ממשיכה בהקשה. ב-Safari וגם כאפליקציה מותקנת.
- **התקנה** (`#/install`): שיתוף ← הוסף למסך הבית; אייקון, מסך פתיחה ושורת סטטוס תקינים; האפליקציה נפתחת במצב טיסה.
- **ייצוא העוגנים ליומן** (הגדרות): ב-Safari נפתח "הוסף ליומן"; באפליקציה המותקנת נפתח גיליון שיתוף.
- **גיבוי** (`#/backup`): ייצוא דרך גיליון השיתוף ("שמור בקבצים"), וייבוא חזרה.
- **מקלדת**: השדה הפעיל נשאר נראה מעל המקלדת; אין זום אוטומטי בשדות.
